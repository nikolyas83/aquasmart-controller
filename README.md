# AquaSmart ESP32 Aquarium Controller

## 🌊 Огляд проекту

AquaSmart - це інтелектуальна система управління акваріумом на базі ESP32 з використанням FreeRTOS. Система забезпечує автоматичне керування освітленням, моніторинг температури та розширену систему планування з річним календарем.

## 🚀 Основні функції

### **Система управління освітленням**
- 5-канальний PWM контроль з корекцією гами
- Підтримка ефектів (схід/захід сонця, нічний режим)
- Можливість створення пресетів конфігурацій

### **Річна система планування**
- Календар на весь рік з денними розкладами
- Довільна кількість переходів між пресетами протягом дня
- Автоматичне завантаження пресетів за розкладом

### **Моніторинг та комунікація**
- Моніторинг температури (DS18B20)
- MQTT для віддаленого керування
- Веб-сервер з REST API
- Файловий менеджер для динамічного оновлення HTML

### **Налаштування та експорт**
- Система пресетів (освітлення + розклади)
- Імпорт/експорт конфігурацій
- Збереження налаштувань у файловій системі

## 🛠 Технічні характеристики

- **Мікроконтролер:** ESP32
- **ОС:** FreeRTOS (багатозадачна архітектура)
- **Освітлення:** PCA9685 PWM драйвер (5 каналів)
- **Температура:** DS18B20 сенсор
- **Час:** DS1307 RTC з NTP синхронізацією
- **Збереження:** LittleFS файлова система
- **Мережа:** WiFi з автоматичним підключенням

## 📋 API Ендпоінти

### Розклади
- `GET /api/schedule/day/YYYY-MM-DD` - отримання розкладу на день
- `POST /api/schedule/day/YYYY-MM-DD` - встановлення розкладу на день
- `GET /api/schedule/year/YYYY` - отримання річного розкладу
- `POST /api/schedule/import` - імпорт розкладу
- `GET /api/schedule/export` - експорт розкладу

### Пресети
- `GET /api/presets/lighting` - отримання пресетів освітлення
- `GET /api/presets/schedule` - отримання пресетів розкладів
- `POST /api/presets/lighting/save` - збереження пресету освітлення
- `POST /api/presets/schedule/save` - збереження пресету розкладу
- `GET /api/presets/export` - експорт всіх пресетів
- `POST /api/presets/import` - імпорт пресетів

## 🔧 Встановлення та збірка

### Передумови
- PlatformIO IDE
- ESP32 плата
- Arduino framework

### Збірка
```bash
# Клонування репозиторію
git clone https://github.com/nikolyas83/aquasmart-controller.git
cd aquasmart-controller

# Відкриття в PlatformIO
platformio run
```

### Прошивка
```bash
platformio run --target upload
```

## 🌐 Веб-інтерфейс

Система має вбудований веб-сервер з файловим менеджером, що дозволяє:
- Керувати файлами системи
- Динамічно оновлювати HTML інтерфейс без перепрошивки
- Моніторити стан системи
- Налаштовувати розклади та пресети
