## Актуальний стан (оновлено 2026-01-30)

- LittleFS монтується централізовано у `src/main.cpp`; перед оновленням статичних файлів використовуйте `pio run -t uploadfs`.
- API: `/api/status` повертає `ssid`, `rssi`, `ip`, `time`, `temperature`. Додані файлові ендпоінти `/list`, `/upload`, `/delete`, `/mkdir` і OTA alias `/api/ota/upload`.
- Presets: створюється `presets/lighting/default.json` при ініціалізації, тож при чистому FS не виникатиме помилок завантаження пресетів.

1. **Ініціалізувати Git репозиторій:**
   ```bash
   git init
   git add .
   git commit -m "[INITIAL] AquaSmart aquarium controller"
   git branch -M main
   ```

2. **Додати на GitHub:**
   ```bash
   git remote add origin https://github.com/yourusername/aquasmart-controller.git
   git push -u origin main
   ```

   - Додати Topics: `esp32`, `iot`, `aquarium`, `automation`
