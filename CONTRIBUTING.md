## 🚀 Як розпочати

1. **Fork** репозиторій на GitHub
2. **Clone** вашу копію:
   ```bash

   ```

3. **Створіть feature гілку:**
   ```bash
   git checkout -b feature/your-feature-name
   ```

```bash

# Запустити тести (якщо є)

```

## 📝 Коммітити та стиль коду

### Commit Messages

Дотримуйтесь формату:

```
[TYPE] Short description

Detailed explanation if needed.
Fixes #123
```

**Types:**
- `[FEATURE]` - Нова функціональність
- `[FIX]` - Виправлення помилки
- `[DOCS]` - Оновлення документації
- `[REFACTOR]` - Рефакторинг коду
- `[TEST]` - Додавання тестів
- `[PERF]` - Оптимізація продуктивності

### Кодовий стиль

- **Мова коду:** C++17
- **Контролер:** ESP32 (Arduino framework)
- **Форматування:** Google C++ Style Guide

```cpp
// Правильно
void handleLightEffects() {
  if (!isInitialized) return;
  // ...
}

// Неправильно
void handleLightEffects(){
if(!isInitialized) return;
}
```

## 🧪 Тестування

Перед відправкою PR:

1. **Build тест:**
   ```bash
   pio run --clean
   pio run
   ```

2. **Перевірка розміру:**
   ```bash
   echo "Flash usage:"
   pio run --target size
   ```

3. **Перевірка синтаксису:**
   ```bash
   pio check --skip-packages
   ```

## Актуальний стан для контриб'юторів (оновлено 2026-01-30)

- LittleFS монтується централізовано в `src/main.cpp`. Якщо ви додаєте код, **не** викликайте `LittleFS.begin()` повторно у модулях.
- Нові та оновлені API: `/api/status` (додає `ssid`), `/api/ota/upload`, `/list`, `/upload`, `/delete`, `/mkdir`. Оновіть тести/фронтенд.
- Presets: при ініціалізації створюється `presets/lighting/default.json`. Якщо змінюєте формат — додайте міграцію у `PresetControl.cpp`.

Перед PR рекомендовано виконати:
```bash
pio run -t uploadfs   # оновити образ LittleFS якщо змінили файли в data/
pio run -t upload     # залити прошивку
pio device monitor -p COM3 -b 115200
```

## 📋 Вимоги до PR

1. **Опис змін** - Чітко опишіть що ви змінили та чому
2. **Посилання на Issue** - Якщо це виправлення, посилання на issue
3. **Тестування** - Подайте результати тестування
4. **Документація** - Оновіть README якщо потрібно
5. **Не містить конфліктів** - Синхронізуйте з `main` гілкою
